# Web Development Internship – Task 1

This repository contains **Task 1** of my Web Development Internship. The task focuses on creating a personal portfolio website and showcasing projects completed during the internship.

## Project Overview

The portfolio website provides an introduction to my work, skills, projects, and resume. It also includes screenshots of the projects developed during the internship.

## Contents

- **index.html** – Main portfolio webpage.
- **style.css** – CSS stylesheet used to design and style the portfolio.
- **resume.pdf** – My resume.
- **Screenshots** – Images showcasing the completed projects and portfolio.

## Projects Showcased

### Random Password Generator

A web-based application that generates random passwords for users.

### To-Do List

A simple task management application that allows users to add and manage tasks.

### Number Guessing Game

An interactive game where users try to guess a randomly generated number.
